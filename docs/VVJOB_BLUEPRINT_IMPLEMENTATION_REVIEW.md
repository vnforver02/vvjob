# VVJOB V1.0 改版评审与实施范围

日期：2026-10-24（越南时间）
依据：PR #1，`docs/vvjob-product-blueprint-v1`。
状态：现有代码审计 + 方案，待产品评审；本文件不代表新增功能已实现。

## 结论
保留 NodeBB / Harmony / VVJOB 插件架构，先收敛导航和页面信息层级，再建设话题与企业评价。匿名是独立安全项目，不能仅隐藏作者名。现有聊天、人脉、认证数据保留；移出主导航不等于删除功能或用户数据。职业认证不作为注册、浏览或普通互动的前置条件。

## 第一批改版提案
1. 手机底栏：Trang chủ、Khám phá、居中发布、Công ty、Cá nhân。通知留在顶部图标；聊天与人脉移入个人页的次级入口。游客点互动才登录，保留返回目标。
2. 桌面左栏采用相同四大入口与发布按钮；中间保留信息流；右侧显示有权限访问的热门话题和轻量引导，无大口号占位。
3. 首页上部：小品牌区、推荐 Dành cho bạn / 最新 Mới nhất / 热门 Nổi bật；推荐先按原生排序与后续关注话题实现，不能宣传 AI 或不存在的个性化。
4. 发现展示四个可用内容方向：Lương & thưởng、Chuyện công sở、Review công ty、Kinh nghiệm đi làm。匿名方向只显示未开放状态；不创建会误导用户的匿名分类入口。旧分类 ID 和历史帖子保留，映射后再迁移名称。
5. 统一线性图标、44px 触控目标、4/8px 间距、越南语排版；文字、空状态、加载和重试一致。默认延续现有蓝色品牌；蓝图紫色 #583BEE 仅作为视觉评审备选。
6. 不改数据库结构，不移除已有帖子、账号、认证或公司；不新增模拟内容。此批先本地预览、评审后实施上线。

## 后续业务规则待定（不擅自实现）
- 企业评价：先收集自愿用户的真实评价；评分聚合的最低样本、有效期、防重复及申诉时限需确认。未达阈值只显示“Chưa đủ đánh giá”，不输出虚构分数。
- 匿名：独立作者投影、授权审计、公开 API/通知/搜索/引用/头像/个人页/附件元数据隔离；内部映射不得返回客户端。全矩阵验证通过前保持关闭。
- 话题关注：复用可行的原生能力或插件存储，须明确唯一标识、权限、分页与取消后行为。
- 原有测试账号继续明确区分合成身份；产品上线前单独制定演示数据清理方案，不能直接删除现有数据。

## 本次文件与影响
同步 PR 六个新增文件：AGENTS.md、产品蓝图、四个 `.agents/skills/vvjob-*/SKILL.md`；新增本评审文档。没有覆盖现有业务修改，没有合并 PR，没有改变生产站。PR 中“规划草案”状态保留。

主要风险：缩减导航影响旧入口发现性；新评价模型和匿名机制涉及权限与隐私；颜色改变影响已有品牌。通过保留路由、分批预览与逐项验收控制，避免一次全站重写。

建议评审顺序：先确认第一批导航与页面提案；再做交互预览；确认后实现与回归；企业评价及匿名分别评审，不捆绑进视觉改版。
